# Angel One SmartAPI Callback

This repository hosts a minimal, static callback page for the Angel One SmartAPI integration.

It is served via GitHub Pages to provide a valid, secure HTTPS callback URL for the SmartAPI application registration.

## Features
- **No Backend**: Pure static HTML.
- **Secure**: No credentials, secrets, or API keys are processed, logged, or stored here.
- **Minimal**: Designed simply to fulfill the HTTPS callback requirement for Angel One SmartAPI apps.

## URL
The callback page is hosted at: `https://varad-01.github.io/angelone-callback/`
